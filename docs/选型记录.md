## 工时与成本估算

预计 16–24 小时：基线跑通 2–4 小时，两个业务工作流 6–8 小时，界面与权限 4–6 小时，验证和交付 4–6 小时。不是承诺完成时间。

按 Flash 峰时输入 $0.30 / 百万 token、输出 $1.20 / 百万 token，假设每天 30 个任务，每个任务全流程累计输入 12,000、输出 3,000 token，模型约 $0.216 / 天。按 3 倍迭代余量约 $0.648 / 天；不含搜索、托管和外部服务。价格来自上述官方页，实际以账单为准。

建议默认应用预算 $1 / 天，最多 6 次模型请求 / 任务，输出上限 4,000 token / 请求；须在每次请求前做额度预留。预算尚待用户接受，未发起任何付费模型调用。
